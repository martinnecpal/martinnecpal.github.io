1 · Introduction to GAMS

General Algebraic Modeling System – what it is, where it is used, how to install and run it

[0:05] Part 1, 20 minutes.
GAMSWhat is it?

What is GAMS?

  • A high-level algebraic modelling language for optimization
  • You write the model as mathematics: sets, parameters, variables, equations
  • GAMS compiles the model and passes it to a solver
  • Same model → different solvers without rewriting
  • Linear, nonlinear, discrete, stochastic, equilibrium – at large scale
Key idea
separate what the problem is (the model)
from how it is solved (the solver)
[0:05–0:07] Emphasize model vs. solver separation: engineers describe physics/economics, the solver handles the algorithm.

Example 1Problem

The problem

$$\begin{aligned} \max\; & Z = 3x_1 + 2x_2 \\ \text{s.t.}\; & x_1 + 3x_2 \le 4 \\ & x_1 + x_2 \le 2 \\ & x_1,\, x_2 \ge 0 \end{aligned}$$

Two variables → solve it graphically, then check the result in GAMS.

Example 1Graphical solution

Graphical solution

Feasible region = polygon A B C D; the optimum of an LP lies in a corner point.

Example 1GAMS code

The same model in GAMS

$Title Simple LP optimisation problem

Positive Variables x1, x2;
Free Variable      Z;

Equations obj, eq1, eq2;

obj..  Z =e= 3*x1 + 2*x2;
eq1..  x1 + 3*x2 =l= 4;
eq2..  x1 +   x2 =l= 2;

Model Example01 /all/;
Solve Example01 maximizing Z using LP;

Display x1.l, x2.l, Z.l;
  • Variables – x₁, x₂ ≥ 0, objective Z free
  • Equations – declared, then defined with ..
  • Model – all equations
  • Solve – direction, objective, model type
  • Display – print the results

GAMSPyWhat is it?

What is GAMSPy?

  • A Python package for algebraic modelling – sets, parameters, variables, equations as Python objects
  • Uses the GAMS engine and solvers in the background
  • No separate GAMS installation – pip install gamspy brings its own GAMS core
  • Works with pandas, NumPy, Matplotlib, Jupyter, web apps
  • Free demo license; free for academics (GAMS Academic Program)

⚠ GAMS and GAMSPy licenses are different – a GAMS license cannot be used for GAMSPy.

GAMSPyExample 1

How to convert – step by step

  1. Import and create a Container – import gamspy as gp, m = gp.Container()
  2. Variables – each declaration becomes gp.Variable(...) with type=
  3. Equations – declare with gp.Equation(...), define with eq[...] = …
  4. Relations – =e= → ==, =l= → <=, =g= → >=; no ;
  5. Model – list of equations + problem, sense, objective
  6. Solve – model.solve() (default LP solver: CPLEX)
  7. Results – .toValue() for scalars, .records (pandas DataFrame) for indexed symbols

⚠ eq1 = x1 + 3*x2 <= 4 without [...] overwrites the Python variable instead of defining the equation.

[0:59–1:00] The [...] pitfall is the most common one.

Sets, parameters and data in GAMSPy

Example after Prof. Elvis Ahmetović; problem from M. R. Eden (2011)

Example 3Problem

The problem

Two feed streams are mixed into an MEA / water mixture.

FeedMEAWaterCost
Feed 180 %20 %80 cent/kg
Feed 268 %32 %60 cent/kg

Product: max. 25 mass.% water

Which mixing ratio gives the minimum cost per 1 kg of mixture?

Mixing of two streams (own work)

[1:05–1:06] MEA = monoethanolamine, a solvent used e.g. in CO2 capture.
Example 3Model

Mathematical formulation

  • \(m_1, m_2\) – mass of feed 1 and feed 2 [kg] (basis 1 kg)
  • \(z\) – cost of 1 kg mixture [cent]
$$\begin{aligned} \min\; & z = 80\,m_1 + 60\,m_2 \\ \text{s.t.}\; & 0.20\,m_1 + 0.32\,m_2 \le 0.25 \\ & m_1 + m_2 = 1 \\ & m_1,\, m_2 \ge 0 \end{aligned}$$

Graphically: m₁ = 0.583, m₂ = 0.417, z = 71.67 cent/kg

Graphical solution of Example 3 (own work)

[1:06–1:08] Original lecture used NLP; all equations are linear, so LP is correct – discussion point.
Example 3Step 1

Step 1 – direct translation

import gamspy as gp
m = gp.Container()

m1 = gp.Variable(m, "m1", type="positive", description="mass of feed 1 [kg]")
m2 = gp.Variable(m, "m2", type="positive", description="mass of feed 2 [kg]")
z  = gp.Variable(m, "z",  type="free",     description="cost [cent/kg]")

obj     = gp.Equation(m, "obj")
water   = gp.Equation(m, "water")
balance = gp.Equation(m, "balance")

obj[...]     = z == 80 * m1 + 60 * m2
water[...]   = 0.20 * m1 + 0.32 * m2 <= 0.25
balance[...] = m1 + m2 == 1

mixing = gp.Model(m, "mixing", equations=m.getEquations(),
                  problem="LP", sense="min", objective=z)
mixing.solve()
z  = 71.667 cent/kg
m1 = 0.583 kg
m2 = 0.417 kg

Example 3Model vs. data

Problem: numbers are inside the equations

  • Costs and compositions are hard-coded – a 3rd feed or component → rewrite the model
  • Real models: hundreds of streams, data from Excel / databases → separate model and data
ConceptGAMSGAMSPy

DataParameter cost(f) /.../;gp.Parameter(m, "cost", domain=f, records=...)

[1:10–1:11] Motivation for sets and parameters.
Example 3Step 2

Step 2 – general (indexed) formulation

  • Sets: \(f\) – feeds, \(c\) – components
  • Parameters: \(cost_f\), \(w_{f,c}\) mass fraction, \(wmax_c\) limit, \(M\) product amount
  • Variable: \(x_f \ge 0\) – mass of feed \(f\) in product
$$\begin{aligned} \min\; & \sum_f cost_f\, x_f \\ \text{s.t.}\; & \sum_f w_{f,c}\, x_f \le wmax_c\, M \quad \forall c \text{ with a limit} \\ & \sum_f x_f = M \end{aligned}$$

➡ The model does not change when you add feeds or components – only the data.

[1:11–1:13] Read the indexed model; compare with the 2-variable version.
Example 3Step 2

Sets and data

import pandas as pd
import gamspy as gp

m = gp.Container()

# Sets
f = gp.Set(m, "f", records=["feed1", "feed2"], description="feed streams")
c = gp.Set(m, "c", records=["MEA", "water"],  description="components")

# Data – composition as a pandas DataFrame (could come from Excel)
composition = pd.DataFrame(
    [["feed1", "MEA", 0.80], ["feed1", "water", 0.20],
     ["feed2", "MEA", 0.68], ["feed2", "water", 0.32]],
    columns=["f", "c", "value"])

w    = gp.Parameter(m, "w", domain=[f, c], records=composition)
cost = gp.Parameter(m, "cost", domain=f, records=[["feed1", 80], ["feed2", 60]])
wmax = gp.Parameter(m, "wmax", domain=c, records=[["water", 0.25]])
M    = gp.Parameter(m, "M", records=1)
[1:13–1:14] Reading from Excel would be one line: pd.read_excel("feeds.xlsx").
Example 3Step 2

Variables, equations, model

x = gp.Variable(m, "x", type="positive", domain=f)

spec    = gp.Equation(m, "spec", domain=c)
balance = gp.Equation(m, "balance")

# one equation for every component c that has a limit
spec[c].where[wmax[c]] = gp.Sum(f, w[f, c] * x[f]) <= wmax[c] * M
balance[...]           = gp.Sum(f, x[f]) == M

mixing = gp.Model(m, "mixing", equations=m.getEquations(),
                  problem="LP", sense="min",
                  objective=gp.Sum(f, cost[f] * x[f]))
mixing.solve()
GAMSPyGAMS equivalent
spec[c]spec(c).. – an equation for each c
.where[wmax[c]]$wmax(c) – only where a limit exists
gp.Sum(f, …)sum(f, …)
